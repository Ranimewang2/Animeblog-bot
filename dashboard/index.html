⏰ Cron-Job.org Setup Guide

Set up automatic daily posting:

1. Go to cron-job.org → Create account

2. New cronjob → Title: Isekai Blog Bot

3. URL: https://YOUR-APP.vercel.app/api/generate

4. Schedule: Daily at 08:00 UTC

5. Headers → Add: Authorization: Bearer YOUR_CRON_SECRET

6. Save → Enable ✅

💡 Add 3 jobs (8am, 2pm, 8pm UTC) = 3 posts/day automatically!
